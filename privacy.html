Data Apa Saja yang Dikumpulkan

Website ini tidak memasang tracking pihak ketiga yang invasif. Satu-satunya data yang tersimpan di browser kamu adalah preferensi tema (terang/gelap) dan bahasa (ID/EN), disimpan lewat localStorage — data ini tetap di perangkat kamu sendiri dan tidak pernah dikirim ke server manapun.

Analytics

Kalau website ini menggunakan analytics (misal Umami atau Plausible), layanan tersebut privacy-friendly: tidak memakai cookie, tidak melacak individu lintas situs, dan hanya mencatat data teragregasi (jumlah kunjungan, halaman populer) untuk membantu pemilik situs memahami trafik secara umum.

Formulir Kontak

Formulir kontak di halaman utama tidak mengirim data ke server manapun — formulir ini hanya membuka aplikasi email kamu dengan isi pesan yang sudah terisi otomatis (mailto:). Nama, email, dan pesan yang kamu ketik hanya diproses secara lokal di browser kamu.

Link Eksternal

Website ini berisi link ke layanan pihak ketiga (GitHub, Instagram, WhatsApp, dll). Kebijakan privasi masing-masing layanan tersebut berlaku terpisah begitu kamu meninggalkan situs ini.

Pertanyaan
